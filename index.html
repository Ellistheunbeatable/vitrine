Two platforms, two truths

Android gets everything.
iPhone gets honesty.

Android can be mirrored and controlled. iPhone can only be mirrored. That is a limit of iOS, not of this app — and the app says so out loud.

Android

Mirror and control

Your phone's screen in a window, driven by your mouse and keyboard. Typing with a real keyboard is the quiet superpower here.

  • Touch and swipe from the mouse
  • Type with your real keyboard
  • Phone audio on the laptop
  • USB (fast) or Wi-Fi (free)
  • Nothing installed on the phone
iPhone & iPad

Mirror only, on purpose

AirPlay puts the iPhone screen on your laptop with sound. Control is not offered because iOS does not allow it — see below.

  • Screen and audio over AirPlay
  • Works with UxPlay, free and open source
  • Vitrine tells you if a receiver is live
  • No mouse or keyboard control
  • No USB

Why iPhone control cannot be built

Apple publishes no way to send touches into iOS from another computer. Mac's iPhone Mirroring uses private Continuity frameworks that only run on Apple silicon with a paired Apple ID. Any Windows app claiming iPhone control is either a remote viewer you install on the phone, or it is not telling the truth. Vitrine mirrors the iPhone and shows you the line instead of hiding it.

Three minutes, once

How it works

No installer daemons, no sign-in, no background service. Vitrine talks to your phone the same way a developer's own tools do.

1

Install Vitrine

Unzip and run. It installs for your user only, needs no administrator rights, and uninstalls from Settings like any app.

2

Turn on Wireless debugging

On the phone: Settings → About → tap Build number seven times → Developer options → Wireless debugging. It shows an address and a code.

3

Paste two addresses

Pair once with the code, connect with the second address, and the phone appears. It stays paired until you switch debugging off.

What it drives

scrcpy and adb, both free and open source. Vitrine downloads a pinned, checksum-verified copy on first use instead of bundling it.

What it stores

Device names and pairing state, in one local file. No telemetry, no analytics, no crash reporting, no accounts.

What it never does

It never asks for your phone PIN, never stores the pairing code, and never uploads a frame. The UI is served from your own machine.

The honest limits

Every tool has edges. These are Vitrine's, written before you hit them rather than after.

!
Latency is realAbout 50–100 ms over USB, 100–200 ms over Wi-Fi. Fine for chat and photos. Not a gaming monitor.
!
Some video goes blackNetflix, Prime and similar apps blank the mirrored surface on purpose. That is DRM working, not a bug.
!
Wi-Fi debugging drops on rebootThe connect port changes. Re-read it from the phone; pairing stays valid, so it takes ten seconds.
!
iPhone control is impossibleFor Vitrine and for every other Windows app. See the section above.
!
It is version 0.1.0Young software. Some phones behave differently from mine. Tell me and I will fix it.
!

You'll probably see a warning. That's expected.

Vitrine is new and unsigned. A code-signing certificate costs money this project does not have yet, so Windows shows a caution message for anything it has not seen many times. Here is exactly how to get past it, and how to check the file yourself.

In your browser: “isn't commonly downloaded”
  1. In your downloads, click See more (or the ⋯ button) next to the file.
  2. Choose Keep.
  3. Click Show more, then Keep anyway.
When you open it: “Windows protected your PC”
  1. Right-click the ZIP → Extract All, then open the setup program.
  2. If Windows warns you: More info → Run anyway.
The engine download fails behind a school or office network

Some networks block github.com, which is where the 11 MB scrcpy engine comes from. You will see a message naming the proxy or the connection, not a silent failure.

Two ways around it: connect through a phone hotspot once (the engine is cached in %LOCALAPPDATA%\Vitrine\engines after that), or drop scrcpy-win64-v5.0.1.zip into that folder by hand. Vitrine checks its SHA-256 before using it either way.

Check the file yourself instead of trusting a badge

Open PowerShell in the folder you extracted to and run:

Get-FileHash .\VitrineSetup.exe -Algorithm SHA256

The first characters must match the hash above. If they do not, delete the file — it did not come from here. The full source is in the repository, and the mirroring engine is scrcpy, used by millions.

Privacy, in plain words

There is no server to trust

Vitrine runs as a local program and opens one local page at 127.0.0.1. That page is served by your own machine and is not reachable from your network.

The only outbound request

One download from GitHub the first time you press Install engine. It is checksum-verified before it is used.

What is never collected

No usage data, no device IDs, no crash reports, no pairing codes. The download counter on this page counts downloads, not people.
